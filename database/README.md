# PostgreSQL: общая база проекта

Каталог хранит будущие материалы по схеме, которая развивается от КР1 к КР4.
На этапе foundation SQL, seed data и работающая БД не создаются.

- `schema/` — будущие SQL-скрипты создания схемы КР1.
- `seed/` — будущие воспроизводимые учебные данные без персональных данных
  и секретов.
- `diagrams/` — будущие ER-диаграммы и пояснения к отношениям.

КР1 и КР2 используют JDBC. В КР3 исходная схема становится базой для JPA;
дальнейшие изменения идут через Flyway в
`backend/src/main/resources/db/migration/`. Порядок перехода и baseline
потребуется согласовать до первой миграции. Подробнее: [DATABASE.md](../docs/DATABASE.md).

Локальные данные PostgreSQL не входят в Git. `.env.example` в корне содержит
только placeholders; механизм загрузки конфигурации пока не реализован.
