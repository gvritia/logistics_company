Запуск КР2 (Windows)
===================

Нужны Docker Desktop, JDK 21 и Maven 3.9 или новее. JavaFX скачивается Maven;
отдельно устанавливать JavaFX SDK не нужно.

1. В корне проекта создайте .env на основе .env.example, укажите пароль БД.
   Файл .env содержит секреты и не должен попадать в Git.
2. Запустите Docker Desktop.
3. Из корня проекта выполните:

   powershell -ExecutionPolicy Bypass -File .\javafx-client\run.ps1

Скрипт ждёт готовности PostgreSQL, собирает корневой проект КР1 и запускает
JavaFX через Maven. Если Maven есть только внутри IntelliJ IDEA, укажите
полный путь к её mvn.cmd параметром -MavenPath.

Ручной запуск из корня проекта:

   docker compose --env-file .env -f infra/docker/compose.kr2.yml up -d --wait
   mvn install
   cd javafx-client
   mvn javafx:run

В IntelliJ IDEA для javafx-client используйте Maven goal javafx:run.
Кнопка запуска Main.main() может выдавать ошибку о JavaFX runtime, поскольку
обычный classpath запуска не добавляет модули JavaFX.

PostgreSQL слушает 127.0.0.1:55432. При первом запуске пустого Docker-тома
схема и демонстрационные данные загружаются из database/schema и database/seed.
Повторный запуск сохраняет существующие данные. Эта собственная КР2 подключается
к БД напрямую через JDBC; backend из архива примера ей не требуется.

Сценарий демонстрации
---------------------

1. Откройте подробности заявки и покажите связанные данные участников.
2. Создайте заявку; сначала оставьте обязательное поле пустым для проверки ошибки.
3. Измените созданную заявку и удалите её после подтверждения.
4. Выполните поиск по грузу, фильтрацию по статусу и клиенту, смените сортировку.
5. Откройте статистику и экспортируйте текущую выборку через FileChooser.

Автоматическая интеграционная проверка (из каталога javafx-client при работающей БД):

   mvn test-compile org.codehaus.mojo:exec-maven-plugin:3.5.0:java '-Dexec.mainClass=com.lcorp.javafx.Kr2IntegrationCheck' '-Dexec.classpathScope=test'

Она создаёт временную заявку, проверяет CRUD, поиск, связи, статистику и CSV,
затем удаляет эту заявку и временный CSV-файл.
