# Console application — КР1

Каталог зарезервирован для будущего выделения консольного Maven-модуля.
Сейчас действующий `pom.xml` и `src/` остаются в корне репозитория:
существующие настройки IDE привязаны к этим путям. Здесь нет отдельного
Maven-проекта. Проверка выполняется из корня: `mvn -B test`.

Каркас новых пакетов находится в
`src/main/java/com/logisticscompany/console/`: `app`, `model`, `repository`,
`service`, `exception`, `config`, `export`, `util`. Это только места для будущего
кода. Существующий пустой `org.exaple.Main` сохранён; запускаемого меню пока нет.

Будущая архитектура: Console UI → Service → Repository/JDBC → PostgreSQL.
Java 21, Maven 3.9+. Модель, CRUD, поиск, фильтры, сортировка, статистика,
бизнес-правила, исключения и XLSX-экспорт появятся в отдельных задачах КР1.

Перенос исходников и POM должен быть отдельной задачей с проверкой сборки
и путей IDE; см. [решения](../docs/DECISIONS.md) и [backlog](../docs/TASKS.md).
