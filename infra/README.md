# Infrastructure

Каркас инфраструктуры проекта; исполняемых скриптов и Docker Compose пока нет.

- `docker/` — место для будущих Dockerfile и Compose-конфигурации КР3.
- `scripts/` — место для будущих вспомогательных скриптов, когда появится
  конкретная воспроизводимая задача.

Сборка существующего Maven-проекта выполняется из корня репозитория:
`mvn -B test`. PostgreSQL и контейнеры для проверки foundation не нужны.
Шаблон переменных окружения находится в корневом `.env.example`;
реальные `.env`, пароли и локальные тома не должны попадать в Git.

См. [DEVELOPMENT.md](../docs/DEVELOPMENT.md) и [ROADMAP.md](../docs/ROADMAP.md).
